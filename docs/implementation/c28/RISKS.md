# BRD-C28 — riesgos y deuda

- Un diff limpio no demuestra que el diseño sea bueno, sólo que cambió donde debía

## Límite de esta evidencia

No hay juez de visión ni revisión humana integrada: el diff mide diferencia, no calidad.

La distancia entre esta campaña y un artefacto entregable está declarada arriba; no se ha disimulado con stubs silenciosos.
